# AD5 4.1 — накопительные раны в подсказке токена

Замените AutoDamage новым файлом этой ветки вместо установленной копии и перезапустите Mod/API.
NPC Forge 2.5.1, прямой JSON-импорт, браузерное окно и Areas 1.3 сохранены.

Все существующие и новые игровые токены (включая не связанные с листом) получают подсказку с нулевыми счётчиками и включённым show_tooltip:
Легкая рана - 0, Средняя рана - 0, Тяжелая рана - 0

Подсказка обновляется при наведении на видимый токен. Скрипт не раскрывает токены со скрытых слоёв.
Поле «Подсказка» управляется AD5: прежний текст в нём заменяется счётчиками.
Картинки, помеченные isdrawing, не считаются игровыми токенами.

## Расчёт
Процент = фактически потерянные HP / HP перед применением эффекта × 100.
Учитывается итог после промаха, спасброска, множителя и поглощения временными HP.
Избыточный урон ниже нуля не учитывается.
- ≤25%: новая рана не добавляется.
- >25%, ≤50%: +1 лёгкая.
- >50%, ≤75%: +1 средняя.
- >75%: +1 тяжёлая.
Процент не округляется перед выбором тяжести. Например, 25.1% — лёгкая рана.
Один результат применения добавляет максимум одну рану; компоненты урона одной карточки складываются.
Раны считаются отдельно для каждого токена. У нескольких целей — независимо.
При 0 исходных HP новых ран нет. Лечение, промах и эффект без потери HP ран не добавляют.
Лечение не снимает уже накопленные раны. Счётчики сохраняются в state при перезапуске API.
Ручное редактирование HP не создаёт рану: учитываются только эффекты, применённые AD5.

## Управление
GM:
```
!ad5 wounds
```
Инициализировать/обновить подсказки всех токенов без сброса существующих счётчиков.
Для обнуления выделите нужные токены:
```
!ad5 wounds reset
```
Undo/redo учитывает HP, состояния и счётчики ран. Если после применения счётчик был сброшен или изменён, старая отмена останавливается до изменения HP.
Существующие индикаторы остатка HP (half-heart/yellow/red/skull) работают отдельно от накопительных ран.
В отчёте мастеру указаны потерянные HP, исходные HP, процент и тяжесть добавленной раны.

## Проверки
`node tests/wounds.cjs`
Пройдены проверки границ, дробных процентов, повторных ударов от текущих HP, поглощения временными HP, избыточного урона, лечения, нулевых HP, PC/NPC, незаполненных токенов, reset и защиты undo/redo. Выполнен прежний набор тестов импорта/состояний/площадей из tests/direct-json.cjs, включённый в тест ран.
Проверка — Node.js с имитацией Roll20 API. В живой кампании и интерфейсе подсказок не запускалось.

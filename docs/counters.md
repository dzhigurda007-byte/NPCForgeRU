# AD5 Counters — счётчики-рамки на токенах

Счётчик — кольцо из N делений вокруг токена. Рамка лежит на слое карты под токеном, переезжает
вместе с ним и перекрашивается в цвет счётчика. Если на токене несколько
счётчиков, они рисуются концентрическими кольцами. Текущие заряды видны также в
подсказке токена («Сила тьмы 2/4»).

Нужны модули: **Counters**, **AutoDamage** 4.3.173+, **Turn Effect** 1.6.22+,
**Events** (AD5 События — без него заряды по событиям не начисляются).

## 1. Картинки рамок (один раз)

В папке `counters/` лежат готовые наборы: `ring-02` … `ring-12`. В наборе на
N делений N+1 картинка: `ring-NN-00.png` — пустая рамка, `ring-NN-NN.png` —
полная. Деления белые, Roll20 перекрашивает их тонированием, поэтому один набор
годится для любого цвета. Свой набор можно нарисовать в том же формате или
перегенерировать: `python3 counters/generate.py 4 7 13`.

1. Загрузите PNG набора в библиотеку Roll20 (именно в свою библиотеку: скрипты
   Roll20 не могут использовать картинки маркетплейса и сторонних сайтов).
2. Любой способ:
   - **многосторонний токен:** создайте Rollable Table, добавьте картинки по
     порядку 00, 01, …, NN, нажмите «Показать как токен» и перетащите на карту;
   - **или** разложите картинки набора на карте в ряд слева направо (00 слева).
3. Выделите токен (или все картинки) и выполните `!ad5counter images`.
   Скрипт запомнит набор для N делений; выделенное можно удалить.

## 2. Строки счётчика в описании способности

Все строки начинаются с `СЧЁТ` — другие модули AD5 их не применяют. Способность
используется как обычно через AD5 (атака, заклинание, действие NPC): после
применения к цели модуль счётчиков читает блок.

| Строка | Смысл |
|---|---|
| `СЧЁТЧИК: Сила тьмы 4` | имя и число делений (1–20). Обязательно |
| `СЧЁТНА: СЕБЯ` / `СЧЁТНА: ЦЕЛЬ` | на кого вешается рамка (по умолчанию СЕБЯ) |
| `СЧЁТСТАРТ: 1` | заряды при наложении (по умолчанию 0) |
| `СЧЁТЗАРЯД: НАЧАЛО ХОДА 1 \| ПОПАДАНИЕ 1` | когда добавляются заряды (несколько — через `\|`) |
| `СЧЁТНАКОП: АТАКА 2 УРОН 5` | бонус за каждый заряд; на токене носителя появляется кнопка «★ Потратить: Имя» — все заряды переходят в бонус к **следующей** атаке, счётчик снимается |
| `СЧЁТПОЛНЫЙ: КНОПКА Удар тьмы` | при полной рамке на токене появляется кнопка «★ Удар тьмы»; после её использования счётчик снимается и кнопка исчезает |
| `СЧЁТПОЛНЫЙ: СРАЗУ` | при полной рамке сразу срабатывает эффект, рамка снимается |
| `СЧЁТПОЛНЫЙ: СРАЗУ ПОВТОР` | то же, но рамка обнуляется и копит снова |
| `СЧЁТПОЛНЫЙ: ЖДАТЬ` | рамка ждёт «детонатора» (`СЧЁТЗАВЕРШИТЬ`) |
| `СЧЁТУРОН: {З}к6 некротическая энергия` | урон эффекта; `{З}` — число зарядов на момент срабатывания |
| `СЧЁТЭФФ: ослеплён 1 + атака -2 3` | состояния и модификаторы эффекта (язык AD5 Effect Turns, §6 подсказки NPC), части через `+` |
| `СЧЁТХОДЫ: 10` | рамка снимается через 10 ходов носителя |
| `СЧЁТЦВЕТ: фиолетовый` | цвет: фиолетовый, красный, синий, голубой, зелёный, жёлтый, оранжевый, розовый, серый, чёрный, белый или `#RRGGBB` |
| `СЧЁТПОВТОР: 1` | повторное применение той же способности к тому же носителю добавляет заряды (например, каждое попадание клинком заряжает печать без отдельного наложения) |
| `СЧЁТЗАВЕРШИТЬ: Метка тьмы` | в **другой** способности: при применении к цели завершает её счётчик «Метка тьмы» — срабатывает эффект с текущими зарядами |

Если `СЧЁТПОЛНЫЙ` не указан: есть урон/эффект и нет накопления → `СРАЗУ`,
иначе рамка просто останавливается на максимуме.

### События для `СЧЁТЗАРЯД` (относительно носителя рамки)

| Событие | Когда |
|---|---|
| `НАЧАЛО ХОДА`, `КОНЕЦ ХОДА` | ход носителя |
| `ПОПАДАНИЕ` | носитель попал атакой |
| `ПОПАДАНИЕ ПО НОСИТЕЛЮ` | по носителю попали |
| `ПОЛУЧЕН УРОН` | носитель получил урон |
| `НАНЁС УРОН` | носитель нанёс урон |
| `ПОПАДАНИЕ ВЛАДЕЛЬЦА` | владелец способности попал по носителю |
| `УРОН ОТ ВЛАДЕЛЬЦА` | носитель получил урон от владельца |
| `НАЧАЛО ХОДА ВЛАДЕЛЬЦА`, `КОНЕЦ ХОДА ВЛАДЕЛЬЦА` | ход владельца |

Число после события — сколько зарядов добавить (по умолчанию 1, можно `-1`).

## 3. Примеры

**1. Усиление: заряд в начале хода, на 4 зарядах — удар.** Описание способности
«Покров тьмы» (на себя):

```
СЧЁТЧИК: Покров тьмы 4
СЧЁТНА: СЕБЯ
СЧЁТЗАРЯД: НАЧАЛО ХОДА 1
СЧЁТПОЛНЫЙ: КНОПКА Удар тьмы
СЧЁТЦВЕТ: фиолетовый
```

«Удар тьмы» — обычная атака/способность в листе. Кнопка «★ Удар тьмы» появляется
на токене при полной рамке; после удара счётчик снимается.

**2. Накопление силы: заряд за каждое попадание, всё — в следующую атаку.**

```
СЧЁТЧИК: Сила тьмы 4
СЧЁТЗАРЯД: ПОПАДАНИЕ 1
СЧЁТНАКОП: АТАКА 2 УРОН 5
```

2 заряда → следующая атака +4 к броску и +10 к урону, заряды списываются.
Попадание этой атакой сразу даёт новый заряд.

**3. Проклятие: копится на цели, при заполнении срабатывает.**

```
ПРВ: ...обычный эффект способности...
СЧЁТЧИК: Проклятие тьмы 4
СЧЁТНА: ЦЕЛЬ
СЧЁТЗАРЯД: НАЧАЛО ХОДА 1 | ПОПАДАНИЕ ВЛАДЕЛЬЦА 1
СЧЁТУРОН: 3к6 некротическая энергия
СЧЁТЭФФ: ослеплён 1
СЧЁТЦВЕТ: красный
```

**4. Метка с детонацией: урон зависит от накопленных зарядов.** Метка:

```
СЧЁТЧИК: Метка тьмы 6
СЧЁТНА: ЦЕЛЬ
СЧЁТЗАРЯД: УРОН ОТ ВЛАДЕЛЬЦА 1
СЧЁТПОЛНЫЙ: ЖДАТЬ
СЧЁТУРОН: {З}к8 некротическая энергия
СЧЁТЭФФ: атака -{З} 1
```

Отдельная способность «Взрыв тьмы» (на цель):

```
СЧЁТЗАВЕРШИТЬ: Метка тьмы
```

Детонировать можно при любом числе зарядов; урон — `{З}к8`.

«Взрыв тьмы» не требует ни атаки, ни команд: при нажатии способности
появляется курсор выбора цели Roll20 (NPCForge 2.8.1+; старые листы —
`!npc-fix`, или кнопка «Выбрать цель» в чате). Метка на выбранном существе
взрывается с уроном по накопленным зарядам.

### Способности без атаки, урона и спасброска

Если в способности есть только строки счётчика, AutoDamage её не обрабатывает
(нет броска), и счётчики применяют её сами при броске карточки:

- `СЧЁТЗАВЕРШИТЬ` — завершает счётчик на цели, выбранной курсором Roll20;
- `СЧЁТЧИК` + `СЧЁТНА: СЕБЯ` — счётчик сразу вешается на токен владельца;
- `СЧЁТЧИК` + `СЧЁТНА: ЦЕЛЬ` — кнопка «Выбрать цель».

Токен владельца: выделенный при нажатии кнопки токена, иначе единственный токен
персонажа, токен, чей сейчас ход, или токен на странице игроков.

## Атака, забирающая заряды (`СЧЁТТРАТА`)

Строка в описании **атаки** (отдельно от блока счётчика):

```
СЧЁТТРАТА: Печать Завета 2к8 излучение | Белый Клинок 1к10 излучение АТАКА 1
```

Атака забирает все заряды названных счётчиков атакующего: за каждый заряд —
формула урона (своим типом, с учётом сопротивлений) и бонус к броску атаки.
Счётчики после этого исчезают. Бонус получает только эта атака (в том числе
все её цели), следующая атака — уже нет. Нужен AutoDamage 4.3.177+.

## Когда счётчик исчезает

- сработал эффект полного счётчика (`СРАЗУ`, `ЖДАТЬ` + детонатор, `!ad5counter complete`);
  исключение — `СРАЗУ ПОВТОР`: счётчик обнуляется и копит снова;
- использована способность-кнопка полного счётчика (`КНОПКА`);
- заряды накопления потрачены кнопкой «★ Потратить» (`СЧЁТНАКОП`) или атакой со `СЧЁТТРАТА`;
- снят эффект, наложенный той же способностью вместе со счётчиком (например,
  помеха от «Проклятия тени» закончилась или снята) — нужен Turn Effect 1.6.24+;
- истекли `СЧЁТХОДЫ`, удалён токен или рамка, мастер снял счётчик.

Счётчик без эффекта у способности (только урон или ничего) снимается только по
правилам выше, кроме связи с эффектом.

## 4. Команды

| Команда | Кто | Что делает |
|---|---|---|
| `!ad5counter images` | GM | зарегистрировать набор рамок из выделенного |
| `!ad5counter list` | GM | счётчики выделенных токенов (или всей карты) и загруженные наборы |
| `!ad5counter set Сила тьмы 3` / `+1` / `-1` | GM | заряды на выделенном токене |
| `!ad5counter remove Сила тьмы` / `all` | GM | снять с выделенного токена |
| `!ad5counter complete Метка тьмы` | GM | завершить: сработает эффект |
| `!ad5counter use TOKEN TARGET\|- Имя способности` | владелец | применить блок счётчика из описания способности листа вручную (обычно не нужно — см. «Способности без атаки…») |

Рамки лежат на слое карты (Map), поэтому никогда не накрывают токены. Мастер может
перейти на слой карты и сменить сторону рамки (ПКМ → «Выбрать сторону»): заряды станут
равны номеру стороны. Рамку нельзя сдвинуть отдельно — она возвращается к
токену. Удаление рамки снимает счётчик; удаление токена — все его счётчики.

# AD5 Turns — единая смена хода

Новый модуль **Turns** (`AD5Turns`). Установите его как отдельный скрипт в Roll20 рядом с остальными; порядок установки не важен.

## Зачем

Раньше 13 модулей сами следили за трекером инициативы и по-разному понимали «новый ход»:

- одни — смена верхней строки;
- другие — смена группы NPC;
- третьи — «поворот» трекера;
- некоторые — любое изменение трекера.

Поэтому правка инициативы мастером могла засчитаться как ход: например, у выданных заклинаний убывали раунды, а у лёгких ран не срабатывал урон. Изменения трекера скриптами (`!npc-init`) модули не видели вовсе.

## Как работает

- Трекер разбирается один раз, событие получают все модули в постоянном порядке:
  Effect Turns → Movement → Concentration, Reactions → Spell Effects → Phases → Events → Condition Engine → Areas → Скрытность → AutoDamage → FX → Counters.
- **Новый ход** — сменилась **группа** наверху трекера:
  - у токена — группа NPC Group Initiative (NPC с одинаковым именем — одна группа, персонаж — сам по себе);
  - у пользовательской строки — её текст.
- **Не ход:**
  - правка значения инициативы;
  - добавление или удаление строк;
  - перестановка внутри одной группы.
- **Раунд** увеличивается, когда трекер поворачивается и наверх возвращается самая высокая инициатива.
- **Записи трекера скриптами** (`!npc-init`, бонус к инициативе из Effect Turns) теперь тоже доходят до всех модулей.

Без модуля Turns все скрипты работают как раньше: каждый слушает трекер сам.

## Команда мастера

`!ad5turns` — номер раунда, список подписчиков по порядку и последнее событие (было ли оно новым ходом).

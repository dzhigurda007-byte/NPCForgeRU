# Частично автоматизированные заклинания: что можно довести до полной автоматизации

Разбор 107 заклинаний со статусом «◐ частично» в каталоге (`!ad5spell-list частично`) на сборке AutoDamage 4.3.157 / Areas 2.27.0 / Spell Library 2.3.22.

По решению кампании **не автоматизируются**: призыв, видимость и иллюзии, взаимодействие с окружением, создание предметов, чисто нарративные и визуальные эффекты.

## Статус (октябрь 2026)

Сделано: механики **1–7 и 9–14** и мелкие одиночные (AutoDamage 4.3.158, Effect Turns 1.6.15, Areas 2.28.0, Concentration 1.2.11, Spell_effects 1.1.4, Spell Library 2.3.23), все проверены в эмуляторе. Механика **8** (принудительное поведение) по решению кампании не делается — перемещения отыгрывают Мастер и игроки. Для потери действия (9) взят свободный маркер `stopwatch` (секундомер).

Данные переведены на «full» (импорт `imports/phb-spells-*.json`, `builtin-spells-all.json`): Защита от оружия, Божественное благоволение, Гневная кара, Доспехи мага, Дружба с животными, Жуткий смех Таши, Луч болезни, Метка охотника (вариант по типу оружия, вкл. магический), Опутывающий удар, Защита от яда, Магическое оружие, Палящий луч, Раскалённый металл, Тишина, Увеличение/уменьшение, Умиротворение, Газообразная форма, Гипнотический узор, Зловонное облако, Метель, Молниевая стрела, Полёт, Рост растений, Аура жизни, Каменная кожа, Оглушающая кара, Огненный щит, Свобода перемещения, Каменная стена, Круг силы, Порченый взгляд, Обратная гравитация, Регенерация, Силовая клетка, Слабоумие, Сокрытие разума, Цунами, Множественное полное исцеление; встроенные — Луч холода, Электрошок, Священное пламя, Мистический заряд, Леденящее прикосновение, Кислотная стрела, Призыв молнии, Усыхание, Ледяная буря, Распад, Солнечный луч.

Остаются «частично»: принудительное поведение (Диссонирующий шёпот, Ужас, Принуждение, Корона безумия), окружение (Землетрясение — трещины, Порыв ветра — направление), Буря возмездия (раунды 3+), а также Луч слабости, Стихийное оружие, Мантия крестоносца, Изгоняющая кара, Маяк надежды, Заражение, Разрушительная волна, Духовные стражи, Проклятие, Неудержимая пляска, Божественное слово, Священная аура, Упругая сфера, Чёрные щупальца — для них нужны ещё не сделанные мелочи (половина урона атак Силой, тип урона у баффа оружия, изгнание по порогу после кары, лечение по максимуму, цели «враги»).

## A. Только правка данных (20)

Синтаксис уже есть; заклинания написаны упрощённо при массовом импорте. Каждую правку нужно прогнать в эмуляторе.

| Заклинание | Что сделать |
|---|---|
| Луч холода | `замедление 10 1` до начала следующего хода заклинателя |
| Электрошок | `реакции 0 1` при попадании |
| Луч болезни | `ПОПАДСПАС: ТЕЛ {DC}` + `ПОПАДПРВ: отравлен 1` |
| Гневная кара | испуг со снятием проверкой `испуган ПРОВЕРКА МДР{DC} 10` |
| Опутывающий удар | `опутан 1д6 СИЛ{DC} 10` — периодический колющий урон, снятие проверкой |
| Оглушающая кара | `пом атака`, `проверка ВСЕ` с помехой, `реакции 0 1` до конца следующего хода цели |
| Божественное благоволение | `ПОПАД: постоянный`, `ПОПАДУСЛ: оружие`, `ПОПАДУРОН: 1d4 излучение` |
| Метка охотника | тип доп. урона из оружия → вариант-меню по типам (колющий/рубящий/дробящий) |
| Стихийное оружие | `ПОПАД` + `ВАРИАНТ` по стихиям, `атака 1` |
| Мантия крестоносца | аура с ПАСС `ПОПАДУРОН: 1d4 излучение` союзникам |
| Проклятие | вариант «лишний урон» — `ПОПАДЦЕЛЬ: цель эффекта`, `ПОПАДУРОН: 1d8 некротическая энергия` |
| Разрушительная волна | цели «враги» (выбор сторон из AD5 Sides) |
| Духовные стражи | цели «враги»; тип урона уже вариантом |
| Заражение | `ВАРИАНТ` по болезням (ослеплён, помеха на проверки СИЛ и т. д.) после `СЧЁТ 3` |
| Рост растений | `ЦЕНА ДВИЖЕНИЯ: 4` (механика появилась в Areas 2.26) |
| Чёрные щупальца Эварда | опутанный получает урон в начале хода; снятие проверкой СИЛ/ЛОВ |
| Изгоняющая кара | порог после удара `ХИТЫ<=50: изгнан` |
| Неудержимая пляска Отто | без спасброска при касте; `УСЛЭФ: ПРЕМ АТАКАМ ПО ЦЕЛИ`, `пом ЛОВ`, `атака` с помехой, `замедление` до 0; снятие спасброском МДР |
| Множественное лечащее слово | решение по правилу Арвенора (только стабилизирует или лечит) — данные, не скрипт |
| Умиротворение | вариант «равнодушие» — снятие очарования/испуга уже работает; оставшееся — нарратив, снять пометку |

## Рекомендуемый порядок

1. **Группа A** — правка данных, один проход импорта: 20 заклинаний.
2. Механики **4, 6, 7, 9, 10, 11** — малые, вместе закрывают 13 заклинаний (и доводят Проклятие и Пляску).
3. Механики **1, 2, 3, 5** — средние, но самые частые в бою: 19 заклинаний.
4. Механики **8, 12, 13, 14** и мелкие одиночные — остальные 21.

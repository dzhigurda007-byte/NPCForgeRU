# Названия заклинаний по официальной локализации (dnd.su)

Названия, школа, компоненты (с текстом материальных компонентов), ритуал, концентрация и формулировки дистанции/длительности сверены с [dnd.su](https://dnd.su/spells/) — официальный перевод «Книги игрока» и дополнений. Где нет официального перевода, dnd.su даёт свой; для всех наших заклинаний он нашёлся, к ttg.club обращаться не пришлось.

Правила Арвенора (круги, камни, концентрация, удалённые заклинания) сохранены. Старое русское название оставлено в `aliases` — поиск `!ad5spell-search` находит заклинание и по нему.

Исправлено попутно: школа Гневной и Оглушающей кары — Воплощение; у Тишины возвращён ритуал (правило Арвенора меняло только концентрацию); компоненты у Необнаружимости, Лабиринта, Полного превращения, Смертного ужаса и ряда заклинаний дополнений.

# AD5 Visibility — скрытность и зрение NPC

Модуль **Stealth** (AD5 Visibility 1.5.0+). Работает с **Sight** (стены, свет,
тёмное зрение) и **Environment** (укрытие). По умолчанию — сбалансированный режим.

## Как спрятаться

Игрок бросает «Скрытность» из листа или кнопкой токена «Скрытность». Итог броска —
Сл, с которой NPC сравнивают Внимательность.

Спрятаться **нельзя на виду**: если хоть один NPC видит персонажа на ярком свету
ближе 60 фт (спереди; со спины — 5 фт) и без укрытия, бросок отклоняется. Нужно одно из:

- выйти из поля зрения (за спину NPC дальше 5 фт, за стену, дверь);
- встать в тень или темноту (и не нести свет);
- встать за укрытие (½, ¾ — по AD5 Environment);
- отойти дальше 60 фт.

Пока персонаж скрыт: маркер скрытности на токене, NPC не используют против него
реакции, на слое мастера метка «◌ Имя» — где он спрятался.

## Общее освещение (`!ad5sight ambient`)

Команда мастера, токены выделять не нужно — свет задаётся для **карты, которую мастер
сейчас открыл**, и действует на всей этой карте (у каждой карты свой общий свет):

```
!ad5sight ambient bright   — ☀️ день
!ad5sight ambient dim      — 🌒 сумерки, лунная ночь
!ad5sight ambient dark     — 🌑 ночь, подземелье
!ad5sight ambient off      — не задано: свет из динамического освещения карты
```

Мастеру приходит сообщение, на какой карте какое освещение включилось (и какое было),
и список других карт с заданным светом. Общий свет —
основа; источники света на токенах (факел, фонарь, «Свет» — яркий и тусклый радиус в
настройках света токена, в том числе старое освещение Roll20) освещают вокруг себя, стены
перекрывают свет. Персонаж, который сам несёт свет, освещён. Игроки визуально карту
темнее не увидят — это расчёт для правил. Если общий свет не задан, свет берётся из
динамического освещения (дневной свет страницы и источники), а без него всё ярко.

## Проверка в ход NPC

Проверяет NPC, чей сейчас ход (при общей инициативе — вся группа), и только если
персонаж у него в поле зрения (сектор 180° по повороту токена, со спины — 5 фт).

| Свет у персонажа | Дистанция (от края до края) | Проверка |
|---|---|---|
| яркий | до 60 фт, без укрытия | **на виду** — замечен без броска |
| яркий | 60–120 фт | пассивная Внимательность |
| яркий | дальше 120 фт | пассивная −5 |
| полутень | до 20 фт / до 60 фт / дальше | −5 / −10 / −15 |
| темнота | любая | не видит (тёмное зрение NPC: темнота → полутень, полутень → яркий) |

Укрытие: ½ −2, ¾ −5 (и снимает «на виду»), полное или стена — не видит.

Свет считается **у персонажа**: если он сам несёт свет (факел, фонарь, «Свет» — свет
настроен на его токене), он освещён, даже стоя в тёмном коридоре. Дистанции яркого
света меняются командой `!ad5stealth bright 60 120 5`.

- **Спокойный NPC** — пассивная Внимательность с поправками, без броска.
- **Персонаж на виду** (зона 100%, яркий свет, без укрытия) — замечен без броска.
- **NPC настороже** — бросок к20 + Внимательность с поправками каждый свой ход,
  итог не ниже пассивной с поправками.

Итог ≥ Сл — NPC замечает, скрытность снимается, в чат всем приходит «Имя, тебя заметили!».

## Настороженность

- **Кнопка токена «Настороже»** — у каждого листа NPC без контроля игрока (переключатель:
  настороже / спокоен). На токене появляется маркер настороженности.
- **Макрос мастера «Тревога»** — все NPC на карте игроков настороже, или «Отбой».
- NPC настораживаются сами:
  - заметивший персонажа;
  - NPC, которые видят заметившего или раскрытого персонажа;
  - NPC, которые видят атаку или заклинание из скрытности.

Кнопки и макрос создаются автоматически при запуске (кнопки — через несколько секунд,
пачками). Вручную: `!ad5stealth alertbuttons`.

## Пример

Плут (Скрытность +7) бросил 22, стражник с пассивной 14 (+4):

- плут на ярком свету в 40 фт перед стражником — замечен сразу;
- в полутени в 40 фт: 14 − 10 = 4 < 22 — не замечает (настороже: нужно 28 на к20);
- на ярком свету в 90 фт: 14 < 22 — не замечает; в 150 фт: 14 − 5 = 9;
- плут с факелом в тёмном коридоре в 40 фт — он на ярком свету, замечен сразу.

## Проверка поля зрения (макрос «Поле-зрения»)

Макрос мастера «Поле-зрения» (или `!ad5stealth fov`) рисует на слое мастера:

- клетки по 10 фт перед NPC по **реальному свету** в каждой клетке для этого NPC
  (общее освещение, источники света, тёмное зрение NPC, стены) — итог проверки цели
  среднего размера: зелёная — на виду, замечен сразу; жёлтая — пассивная; оранжевая —
  −5; красная — −10; тёмно-красная — −15; пусто — не видит (темнота, стена);
  белые контуры 20 и 60 фт, синяя зона — со спины 5 фт;
- фиолетовый круг — тёмное зрение NPC;
- подпись над NPC — пассивная Внимательность, «НАСТОРОЖЕ», дальность тёмного зрения;
- линию к каждому персонажу на карте с решением по текущим правилам:

| Линия | Значение |
|---|---|
| красная | заметит / на виду (спрятаться нельзя) |
| жёлтая | NPC настороже — решит бросок (подпись: нужное на к20 и шанс) |
| зелёная | не заметит |
| синяя | персонаж открыт — подпись: какая Скрытность нужна, чтобы спрятаться |
| серая | не видит: вне поля зрения, стена, темнота, полное укрытие |

Рисунок обновляется сам: при перемещении и повороте NPC, перемещении персонажей,
скрытии и раскрытии, смене настороженности, смене общего освещения, перемещении или
изменении источников света. Режимы макроса: выделенные (без
выделения — все NPC), все NPC на карте, обновить, убрать у выделенных, убрать все.

## Команды мастера

| Команда | Что делает |
|---|---|
| `!ad5stealth status` | кто скрыт, кто настороже, что видит каждый NPC |
| `!ad5stealth alert [TOKEN_ID] [on\|off]` | настороже (без id — выделенные) |
| `!ad5stealth alarm on\|off` | тревога / отбой для всех NPC карты |
| `!ad5stealth mode balanced\|strict` | сбалансированный / строгий режим |
| `!ad5stealth bright 60 120 5` | дистанции яркого света: на виду, без штрафа, штраф дальше |
| `!ad5stealth fov [on\|all\|refresh\|off\|clear]` | поле зрения и решения по персонажам (макрос «Поле-зрения») |
| `!ad5stealth alertmarker ИМЯ` | маркер настороженности (пусто — автоподбор) |
| `!ad5stealth reveal [all]`, `!снять-скрытность` | снять скрытность |
| `!ad5stealth check` | проверка NPC текущего хода сейчас |

**Строгий режим** (`mode strict`, прежнее поведение): спрятаться можно где угодно,
каждый NPC бросает к20 каждый свой ход (зона 50% — помеха, 25% — помеха и −5, итог
не ниже пассивной).

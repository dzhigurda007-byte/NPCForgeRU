# Подсказка для генератора заклинаний (ChatGPT) — кампания «Арвенор»

> Синтаксис сверен со скриптами: Spell Library 2.3.25, AutoDamage (AD5) 4.3.160, Effect Turns 1.6.17,
> Areas 2.29.0, Concentration 1.2.13, Reactions 1.6.12, Spell_effects 1.1.5, Phases 1.1.5.
> Образцы — файлы `imports/*.json` (466 записей, все проверены в эмуляторе Roll20).

## Как пользоваться в ChatGPT

**Вариант 1 — проект или свой GPT (рекомендуется).**
1. ChatGPT → «Проекты» → новый проект (или «Мои GPT» → «Создать»).
2. Поле «Инструкции»: вставьте блок из **части 1** целиком (он короче 8000 знаков — лимита поля).
3. «Файлы проекта» / «Знания»: загрузите **этот файл целиком** (`spell-generator-prompt.md`). Для образцов можно загрузить ещё `imports/expansion-spells.json` и `docs/arvenor-spell-rules.md`.
4. В чате проекта пишите задание: «Сделай заклинание Огненный шар», «Придумай заклинание 3 круга для некроманта культа: …», «Переведи эти 5 заклинаний из Tasha's».

**Вариант 2 — без проекта.** Вставьте весь файл первым сообщением, ниже — задание.

**Что делать с ответом.** Скопируйте JSON. В чате Roll20 (как ГМ) напишите `!ad5spell-json`, вставьте JSON в GM Notes раздатки «AD5 Spell Library — JSON Import», сохраните и нажмите «Добавить / обновить». Импорт проверит поля и покажет ошибки. Затем добавьте заклинание персонажу: `!ad5spell Название`.

### 3. Формат ответа

- Один блок ```json, внутри массив записей. До 200 записей за раз (лимит импорта).
- Строгий JSON. Числа — числами (`"level": 3`), логические — `true`/`false`.
- Перевод строки в `description` — `\n`. Каждая механическая директива — с новой строки.
- После блока — максимум 3 строки: что ручное и в чём сомнения.

### 4. Схема записи

#### 4.1. Поля

| Поле | Тип | Обяз. | Значение |
|---|---|---|---|
| `id` | строка | да | `A-Z a-z 0-9 _ . : -`, до 100 знаков. `phb-fireball`, `xge-chaos-bolt`, `arv-ash-veil`. Повторный импорт с тем же `id` обновляет запись. |
| `name` | строка | да | Официальное русское название (§1). |
| `aliases` | массив строк | да | `["Fireball", "Огненный шар", "Фаербол"]`. |
| `level` | число | да | 0 (заговор) … 9. |
| `school` | строка | да | `Ограждение` · `Вызов` · `Прорицание` · `Очарование` · `Воплощение` · `Иллюзия` · `Некромантия` · `Преобразование`. |
| `castingTime` | строка | да | `1 действие` · `1 бонусное действие` · `1 реакция` · `1 минута` · `10 минут` · `1 час` · `8 часов` · `12 часов` · `24 часа`. |

| `target` | строка | да | §4.3 — текст цели или геометрия области. |
| `duration` | строка | да | §4.4. |

| `ritual` | логическое | нет | `true` для ритуалов. |
| `classes` | строка | да | Через запятую: `Бард`, `Жрец`, `Друид`, `Паладин`, `Следопыт`, `Чародей`, `Колдун`, `Волшебник`, `Изобретатель`. |

#### 4.2. Дистанция (`range`)

| Значение | Когда |
|---|---|
| `30 фт`, `120 фт`, `1 миля` | Обычная дистанция до цели или до точки области. |
| `Касание` | Касание. |
| `На себя` | Цель — сам заклинатель; выбор цели **не открывается**. Также для конуса/линии/области от себя (геометрия — в `target`) и для `ВКР`. |
| `Реакция` | Реакция на событие с самим заклинателем (Щит, Поглощение стихий). |
| `Реакция 60 фт` | Реакция на событие в пределах 60 фт (Контрзаклинание, Адское возмездие). |
| `В пределах видимости`, `Без ограничений`, `Особая` | Нарративные дистанции. |

Важно: если заклинание по книге «на себя», но бьёт **другое** существо одной целью (Первобытная дикость, Молниевое притяжение, Разящее око), пиши реальную дистанцию (`5 фт`, `15 фт`, `60 фт`) — иначе урон попадёт в заклинателя.

#### 4.3. Цель и области (`target`)

- Одна цель: `1 существо`, `1 гуманоид`, `1 согласное существо`, `1 предмет`, `на себя`.
- Несколько целей: `до 3 существ`, `до 6 существ в 30 фт круге` — скрипт запросит выбор нескольких целей. Число целей по кругу ячейки — строка `ЦЕЛЕЙ: 3+{ПОВ}` в `description` (§5.3).
- Область (шаблон на карте → «Применить»):

| Запись | Фигура |
|---|---|
| `20 фт круг` / `20 фт сфера` | круг радиусом 20 фт |
| `15 фт конус` | конус длиной 15 фт (с `range: "На себя"` — от заклинателя) |
| `30 фт куб` / `20 фт квадрат` | куб/квадрат с ребром |
| `линия 5/100 фт` | ширина/длина; `линия 5/60/20 фт` — ширина/длина/высота (стены) |
| `5/40 фт цилиндр` | цилиндр радиусом 5 фт и высотой 40 фт (без высоты — по росту заклинателя) |
| `аура 15 фт, обл` | аура вокруг заклинателя, двигается с ним (Духовные стражи) |

- `, обл` — постоянная зона на длительность заклинания (или пока длится концентрация). Нужны фазы (§6.6). `, обл 10` — зона на 10 раундов.
- Свойства зоны через запятую: `ЗАСХАЙ` (сильное заслонение), `ЗАСЛОУ` (слабое), `СОЛИД` (непроходимо), `ФИЗ` (физический объём), `ПОКР` (игнорирует укрытие).
- Защиту сторон задаёт текст цели: «союзные существа» / «союзник» — только союзники заклинателя; «враждебные существа» / «противник» — только враги. Иначе — все в области.
- Урон области бросается один раз на всех. Укрытие даёт преимущество на спас ЛОВ, полное укрытие исключает цель.

#### 4.4. Длительность (`duration`)

Официальные формулировки: `Мгновенно` · `1 раунд` · `1 минута` · `10 минут` · `1 час` · `8 часов` · `24 часа` · `10 дней` · `Концентрация, до 1 минуты` · `Концентрация, до 10 минут` · `Концентрация, до 1 часа` · `Пока не рассеяно` · `Пока не рассеяно или не сработает` · `Особая`.

Концентрацию скрипты ведут сами: слово «Концентрация» в длительности + `"concentration": true`. Эффекты, зоны и дарованные действия исчезают при потере концентрации; урон вызывает спасбросок концентрации.

### 5. Описание (`description`)

#### 5.1. Структура

```
ЗАКЛ
Примечание: <что делается вручную; кратко, одним-двумя предложениями>.
<механическая строка 1>
<механическая строка 2>
```

- `ЗАКЛ` — первая строка всегда (скрипт добавит сам, если забыть, но пиши явно).
- `Примечание:` — одна строка. Пишется, когда что-то остаётся вручную или игроку надо знать порядок действий («нажмите заклинание, затем атакуйте оружием»). Для полностью автоматических простых заклинаний не обязательно.
- Механические строки — каждая с новой строки, синтаксис §6.

#### 5.2. Типы урона и эффекта

Ровно эти слова в `damageType`, `damageType2`, в формулах внутри директив и в защитах:

`кислота` · `дробящий` · `холод` · `огонь` · `силовое поле` · `электричество` · `некротическая энергия` · `колющий` · `яд` · `психический` · `излучение` · `рубящий` · `звук` · `лечение` · `временное хп`

Оружейный урон с учётом магичности: `руб`/`кол`/`дроб` (немагический) и `магический рубящий` / `маг руб`, `маг кол`, `маг дроб`.

#### 5.3. Плейсхолдеры и повышение круга

| Запись | Значение |
|---|---|
| `{DC}` | СЛ спасброска заклинателя: `парализован МДР{DC} 10`, `ПОПАДСПАС: МДР {DC}`, `убежище {DC} 10` |
| `{КРУГ}` | круг ячейки, которой сотворено заклинание |
| `{БАЗКРУГ}` | базовый круг заклинания |
| `{ПОВ}` | на сколько кругов повышено (`{КРУГ}` − `{БАЗКРУГ}`) |
| `ЦЕЛЕЙ: 3+{ПОВ}` | число целей по кругу (Благословение, Удержание чудовища) |
| `ДЛИТЯЧ: 1-2=1 час \| 3-4=8 часов \| 5-9=24 часа` | длительность по кругу ячейки |
| `({ПОВ}+2)d6` | формула урона с ростом по кругу (во вторичной области, в фазах) |

Внутри фигурных скобок разрешены `+ - * / ( )`, `min()`, `max()`, `floor()`, `ceil()`, `round()`. Основной урон растёт через `higherDieCount`/`higherDieType` — плейсхолдеры для него не нужны.

### 6. Механика (директивы)

#### 6.1. Спасбросок и исходы

```
ПРВ: полный урон, отравлен 1; УСП: половина урона
```

- `ПРВ:` — провал, `УСП:` — успех. Внутри ветки элементы через запятую, ветки разделяй `;`.
- Урон: `полный урон` · `половина урона` · `нет урона`; `нет эффекта` — ничего не происходит.
- Если `УСП` не указан — при успехе 0 урона и 0 эффектов. Исключение: только `ПРВ: полный урон` без `УСП` — полный урон при любом исходе.
- Длительность — число раундов в конце элемента: `оглушён 1`. Без числа — бессрочно (снимается вручную, спасброском снятия или с концентрацией).
- Натуральная 1 на спасброске — провал, урон ×1,5, длительность +1; натуральная 20 — успех, эффекты не накладываются, урон успеха ещё раз делится пополам (правило кампании, считает скрипт).

#### 6.3. Периодический урон и спасбросок снятия

- Урон в начале хода цели: `горение 1д6 2`, `отравлен 2д8 3`, `обморожение 2д4 4`. С явным типом: `опутан 1d6 колющий ПРОВЕРКА СИЛ{DC} 10`.
- Спасбросок снятия в конце каждого хода цели: `состояние ХАР{DC} N` — характеристика **слитно** с СЛ, затем максимум раундов: `парализован МДР{DC} 10`, `ослеплён ТЕЛ{DC} 10`. Характеристики: `СИЛ ЛОВ ТЕЛ ИНТ МДР ХАР`.
- Проверка вместо спасброска: `испуган ПРОВЕРКА МДР{DC} 10`, `в лабиринте ПРОВЕРКА ИНТ20`.
- Счёт успехов и провалов: `опутан ТЕЛ{DC} СЧЁТ 3 → окаменел` — 3 успеха снимают, 3 провала заменяют на указанное (Окаменение плоти, Заражение).
- Успешный спасбросок снятия снимает все эффекты того же применения.

#### 6.4. Боевые модификаторы (баффы и дебаффы)

Элементы в ветках или прямыми строками; последнее число — длительность в раундах. **Всегда указывай длительность.**

| Запись | Смысл |
|---|---|
| `атака +1д4 10`, `атака -2 2` | бонус/штраф к броскам атаки |
| `урон 1д4 10` | бонус к урону |
| `кд 2 10`, `кд -2 1` | модификатор КД |
| `спас МДР +1д4 10`, `спас ВСЕ +1д4 10` | модификатор спасброска (одной характеристики или всех) |
| `проверка СИЛ +1д4 3`, `проверка ВСЕ +1д4 10` | модификатор проверок |
| `прем МДР 10`, `пом ЛОВ 2`, `прем все 10` | преимущество/помеха на спасброски |
| `прем атака 10`, `прем атака оружием 100`, `прем атака рукопашное оружие 10`, `прем атака дальнобойное оружие 10`, `прем атака заклинание 10`, `пом атака 1` | преимущество/помеха на атаки носителя |
| `при уроне прем атака 600` | после получения урона — преимущество на следующую атаку |
| `сопр огонь 10`, `сопр огонь/холод 10`, `сопр огонь 25% 10`, `сопр все 10` | сопротивление урону |
| `сопр оружие 10`, `сопр немаг оружие 10`, `сопр маг оружие 10` | сопротивление урону оружием |
| `имм яд 10`, `имм очарован 10` | иммунитет к урону или состоянию |
| `теряет сопр огонь 10` | сопротивление носителя этому типу не действует |
| `урон по цели 2d6 огонь раз в ход 10` | первое попадание по носителю за ход наносит доп. урон |
| `при движении 1d8 звук 2` | урон, когда носитель сам перемещается |
| `макс хиты +5 999` | максимум и текущие хиты +5 |
| `скорость +10 600` | скорость |
| `полёт 60 100`, `полёт 0 10` | скорость полёта; `0` — запрет полёта |
| `размер +1 10`, `размер -1 10` | увеличение/уменьшение (токен ×2/×½, урон оружием ±1d4) |
| `регенерация 5 10` | лечение в начале хода |
| `оживление 1 10` | при падении до 0 хитов встаёт с 1 хитом |
| `макс хитов не снижается 10` | защита от снижения максимума |
| `концентрация -1д6 10` | штраф к спасброскам концентрации |
| `инициатива +1d8 999` | разовая прибавка к инициативе |
| `при окончании ТЕЛ15 истощение 100` | по окончании эффекта спасбросок, при провале — состояние |
| `переносится 60 10` | эффект можно перенести на другую цель в 60 фт (`!ad5fx transfer`) |
| `прем спас против заклинаний 10`, `прем спас против очарован 10`, `увёртливость против заклинаний 10` | контекстные преимущества |
| `реакции 0 1` | без реакций |
| `убежище {DC} 10` | атакующий носителя проходит спас МДР, иначе выбирает другую цель |

Строка `БЕЗ УКРЫТИЯ` — цель не получает бонуса укрытия к спасброску (Священное пламя).

#### 6.5. Снятие эффектов, хиты, смерть

| Запись | Смысл |
|---|---|
| `снимает ослеплён/оглохший/отравлен/парализован` | снимает перечисленные состояния |
| `снимает проклятие`, `снимает истощение 1`, `снимает снижение максимума` | снятие проклятия, уровня истощения, снижения максимума хитов |
| `рассеивает 3` | эффекты заклинаний до 3 круга снимаются, выше — проверка 10 + круг |
| `стабилизирует` | стабилизирует умирающего |
| `возвращает к жизни 1` | возвращает погибшего с 1 хитом |
| `НЕ НИЖЕ 1` | урон не опускает хиты ниже 1 |
| `СНИЖ МАКС` | максимум хитов снижается на полученный урон |
| `ВАМП`, `ВАМП 50%` | заклинатель лечится на половину (или указанную долю) нанесённого урона |
| `СМЕРТЬ ПРИ 0` | цель на 0 хитов умирает без спасбросков от смерти |
| `ПУЛ ЛЕЧЕНИЯ: 700` | общий запас лечения на всех целей |
| `ХИТЫ<=100: смерть` | эффект, если хиты цели не выше порога; несколько строк — срабатывает самая строгая |
| `ЦЕНА: 4d8 некротическая энергия` | заклинатель платит хитами (без сопротивлений) |
| `ЛЕЧЕНИЕ ЦЕЛИ: ×2` | цель лечится на удвоенную цену |
| `КОСТИ ХИТОВ: 1, МОД` | цель может потратить 1 кость хитов и прибавить модификатор |
| `УРОН ЕСЛИ РАНЕН: Урон2 вместо Урон1` | по раненой цели (хиты ниже максимума) идёт урон 2 |

#### 6.6. Зоны и фазы

Постоянная зона: `target` с `, обл` (или аура) + фазы в `description`:

| Директива | Когда срабатывает |
|---|---|
| `КАСТ:` | при сотворении (на всех в зоне) |
| `ВХОД:` / `ВЫХОД:` | существо вошло / вышло (в том числе прошло насквозь) |
| `ОБЛН:` / `ОБЛК:` | существо начинает / заканчивает ход в зоне |
| `ПАСС:` | пока существо внутри (модификаторы, `труднопроходимая местность`) |
| `МУВ:` | при перемещении внутри: `МУВ: 2д4 колющий` за каждые 5 фт |
| `НАЧК:` / `КНЦИ:` | начало / конец хода заклинателя |
| `НАЧТ:` / `КНЦТ:` | начало / конец хода цели (носителя) |
| `ОКОН:` | при окончании эффекта |
| `ОСВОБ:` | действие цели «освободиться»: `ОСВОБ: опутан, ПРОВЕРКА СИЛ{DC}` |

- Внутри фазы — прямые элементы или ветки `ПРВ:`/`УСП:`. Несколько фаз на одной строке разделяй точкой: `ВХОД: ПРВ: Урон1, полный урон; УСП: Урон1, половина урона. ОБЛН: ПРВ: Урон1, полный урон; УСП: Урон1, половина урона`.
- `Урон1`, `Урон2` — ссылка на `damage` / `damage2`. В фазе можно указать свой урон: `2d6 огонь`.
- `РОСТ 1д6` — урон фазы растёт на 1d6 за каждый ход концентрации (Отсроченный огненный шар).
- Условие: `НАЧТ: ЕСЛИ …: ПРВ: …`.

Директивы зоны (отдельные строки):

| Запись | Смысл |
|---|---|
| `СОПР: огонь 50%`, `ИММ: звук` | защита для находящихся внутри |
| `КОНЦЕНТРАЦИЯ: ТЕЛ` | в зоне нужно проходить спас концентрации |
| `ТИШИНА` | внутри нельзя творить вербальные заклинания |
| `ДРЕЙФ: 10` | зона смещается на 10 фт от создателя в начале его хода |
| `КОЛЬЦО: 5` | действует только полоса 5 фт у края круга |
| `СТОРОНА: 10 ОТ ЗАКЛИНАТЕЛЯ` / `К ЗАКЛИНАТЕЛЮ` / `ВНУТРЬ` / `НАРУЖУ` | у стены/кольца — опасная сторона 10 фт |
| `АНТИМАГИЯ: 5`, `АНТИМАГИЯ: ВСЕ` | заклинания до 5 круга (или все) не действуют внутри |
| `ГРАВИТАЦИЯ: 100` | изменение тяготения в зоне |
| `ПОСТОЯННА ПОСЛЕ: 100` | зона остаётся после 100 раундов концентрации |
| `ОСЛАБЕВАЕТ: 1` | урон зоны уменьшается каждый раунд (Цунами) |
| `РАУНД: 2, ПРВ: Урон2, полный урон; УСП: Урон2, полный урон` | эффект конкретного раунда (Буря возмездия) |
| `ЛИМИТ: 1+МОД` | зона срабатывает не больше 1 + модификатор раз (Исцеляющий дух) |
| `ЦЕНА ДВИЖЕНИЯ: 2` | каждый фут стоит 2 фута скорости |
| `ВСТРЯСКА` | союзник действием снимает эффект зоны с существа |
| `СЛЕД: 100, ЦЕНА ДВИЖЕНИЯ 2` | у мгновенной области — остаётся труднопроходимый след на 100 раундов |
| `ОБЛАСТИ: 4` | до 4 шаблонов одним «Применить» (Огненная буря, Метеоритный дождь) |

Стены (`target` вида `линия 0,5/10/10 фт, обл, СОЛИД`):

| Запись | Смысл |
|---|---|
| `ПАНЕЛИ: 10` | до 10 панелей одного каста, кнопка «Новая панель (k/10)» |
| `ВЫТЕСНЕНИЕ: ЗАКЛИНАТЕЛЬ` / `ВЫТЕСНЕНИЕ: ЛОВ` | существо на месте стены выталкивается в выбранную сторону |
| `ПРОЧНОСТЬ: КД 15, 180 хитов`, `, УЯЗВ огонь`, `, ИММ холод`; `ПРОЧНОСТЬ: НЕРАЗРУШИМА` | токен прочности панели |
| `ПРИ РАЗРУШЕНИИ: СПАС ТЕЛ, ВХОД: ПРВ: Урон2, полный урон; УСП: Урон2, половина урона` | зона на месте разрушенной панели |
| `ЗАЩИТА ОТ СНАРЯДОВ` | дальние атаки оружием сквозь стену промахиваются |
| `СЛОЙ: Красный; тип огонь; ПРВ: Урон1, полный урон; УСП: Урон1, половина урона; блок снаряды; разрушает: холод 25` | слой многослойной стены |
| `ВОКРУГ: 20, СПАС ТЕЛ, ПРВ: ослеплён 10; УСП: нет эффекта` | зона вокруг стены |
| `РАЗРУШАЕТ СТЕНУ` | заклинание уничтожает панель стены (Распад) |

#### 6.7. Вокруг заклинателя без шаблона (`ВКР`)

```
ВКР круг 10 фт
ПРВ: полный урон; УСП: половина урона
```

`range: "На себя"`, `target: "каждое существо в 10 фт вокруг заклинателя"`. Эффект применяется ко всем токенам в радиусе, кроме заклинателя, сразу при нажатии — без шаблона и без выбора цели (Вспышка мечей, Руки Хадара, Слово сияния, Раскат грома). `ВКР куб 15 фт` — квадрат.

#### 6.8. Варианты на выбор

```
Примечание: тип урона выбирается при нажатии.
ВАРИАНТ: Огонь
ТИП: огонь
ВАРИАНТ: Холод
ТИП: холод
```

При нажатии Roll20 показывает меню. Строки до первого `ВАРИАНТ` действуют всегда. Внутри варианта: `ТИП:` / `ТИП2:` — тип урона 1/2, `ЦЕЛЬ:` — своя область (`ЦЕЛЬ: 10 фт круг, обл`), любые эффекты и фазы. Название варианта — без запятых и `|`.

#### 6.9. Снаряды и пул

| Запись | Смысл |
|---|---|
| `МУЛЬТИ: СНАРЯДЫ` | несколько снарядов по выбранным целям |
| `СНРКОЛ: 3` | число снарядов; `СНРКОЛ: УРОВЕНЬ 5/11/17` — растёт с уровнем персонажа |
| `СНРУРОН: 1d4+1 силовое поле` | урон снаряда |
| `СНРПОП: АТАКА` | каждый снаряд — отдельная атака (без строки — попадают автоматически) |
| `СНРВЫШЕ: +1 ЗА КРУГ` | +1 снаряд за каждый круг выше |
| `СНРРАЗНЫЕ: да` | каждый снаряд — в разную цель |
| `СНРПРОВАЛ1: в заклинателя` | при 1 на кубе снаряд летит в заклинателя |
| `МУЛЬТИ: ПУЛ` + `ПУЛ: 5d8` + `ПУЛВЫШЕ: +2д8 ЗА КРУГ` + `ПУЛЭФФ: без сознания 10` | пул хитов, от слабейших к сильнейшим (Усыпление, Сверкающие брызги) |
| `ТИП ПО КУБУ: d8: 1 кислота, 2 холод, …` | тип урона определяется броском |
| `ПЕРЕСКОК: ДУБЛЬ, 30 фт` | при дубле на кубах — кнопка перескока на другую цель в 30 фт |

#### 6.10. Удары и кары (эффекты при попадании оружием)

Заклинание вешает на заклинателя заряд; следующее подходящее попадание добавляет эффект.

```
ПОПАД: разовый
ПОПАДУСЛ: рукопашное оружие
ПОПАДУРОН: 2d6 излучение
ПОПАДСПАС: МДР {DC}
ПОПАДПРВ: испуган ПРОВЕРКА МДР{DC} 10
```

| Директива | Значения |
|---|---|
| `ПОПАД:` | `разовый` · `постоянный` · `12 раз` (столько попаданий) |
| `ПОПАДУСЛ:` | `атака` · `оружие` · `рукопашное оружие` · `дальнобойное оружие` · `заклинание` |
| `ПОПАДЦЕЛЬ:` | `любая` · `цель эффекта` |
| `ПОПАДУРОН:` | доп. урон: `1d6 огонь` |
| `ПОПАДСПАС:` / `ПОПАДПРВ:` | спасбросок и эффект при провале |
| `ПОПАДЭФФ:` | эффект без спасброска: `горение 1д6 ТЕЛ{DC}`, `при движении 1d8 звук 2` |
| `ПОПАДКОН:` | `завершить` · `сохранить` концентрацию после срабатывания |
| `ПОПАДЗАМЕНА: да` | урон кары вместо урона оружия |
| `ПОПАДПРОМАХ: половина` | при промахе — половина урона |
| `ПОПАДОБЛ: 5 фт круг` + `ПОПАДОБЛУРОН:` + `ПОПАДОБЛСПАС: ЛОВ {DC}` + `ПОПАДОБЛПРВ:` / `ПОПАДОБЛУСП:` + `ПОПАДОБЛИСКЛ: основную` | область вокруг поражённой цели |
| `ПОПАДСОСЕД: 5 фт, МОД огонь` | урон второму существу рядом с целью (Клинок зелёного пламени) |

`range: "На себя"`, `target: "на себя"`, `castingTime` — как в книге (обычно бонусное действие).

#### 6.11. Условные эффекты (метки, лучи, разовые бонусы)

| Запись | Смысл |
|---|---|
| `УСЛЭФ: ПРЕМ АТАКАМ ПО ЦЕЛИ` / `ПОМ АТАКАМ ПО ЦЕЛИ` | атаки по носителю с преимуществом/помехой |
| `УСЛЭФ: ПРЕМ АТАКАМ ИСТОЧНИКА ПО ЦЕЛИ` | только атаки заклинателя |
| `УСЛЭФ: ПОМ АТАКАМ ЦЕЛИ` / `ПРЕМ АТАКАМ ЦЕЛИ` | атаки самого носителя |
| `УСЛЭФ: ПОМ АТАКАМ ЦЕЛИ НЕ ПО ИСТОЧНИКУ` | помеха носителю против всех, кроме заклинателя |
| `РАСХ: АТАКА ПО ЦЕЛИ 1` · `РАСХ: АТАКА ИСТОЧНИКА ПО ЦЕЛИ 1` · `РАСХ: ЦЕЛЬ АТАКОВАЛА 1` · `РАСХ: СПАСБРОСОК 1` · `РАСХ: ПРОВЕРКА 1` | эффект тратится после N событий |
| `ДО: КОНЕЦ СЛЕДУЮЩЕГО ХОДА ИСТОЧНИКА` / `ДО: НАЧАЛО СЛЕДУЮЩЕГО ХОДА ИСТОЧНИКА` | срок жизни эффекта |
| `ПОКА: КОНЦЕНТРАЦИЯ АКТИВНА` · `ПОКА: ДИСТАНЦИЯ <= 30 ФТ` · `ПОКА: ВРХП ЭТОГО ЭФФЕКТА > 0` | условие существования |
| `СНЯТЬ: ЦЕЛЬ УМЕРЛА` · `СНЯТЬ: ЦЕЛЬ ПОЛУЧИЛА УРОН` · `СНЯТЬ: ЦЕЛЬ ПОЛУЧИЛА УРОН ОТ ИСТОЧНИКА ИЛИ ЕГО СОЮЗНИКА` · `СНЯТЬ: ЦЕЛЬ АТАКОВАЛА` | условие снятия |
| `ПОВТОР: действие` / `ПОВТОР: бонусное действие` | кнопка «Повторить» без ячейки, пока длится концентрация (Призыв молнии, Раскалённый металл) |
| `ПРОМАХ: половина урона` | при промахе атакой заклинания — половина урона |
| `ТОЛЧ 10`, `ТЯГ 10 фт` | оттолкнуть / притянуть цель на 10 фт (можно внутри ветки) |
| `ЗАВЕРШАЕТ КОНЦЕНТРАЦИЮ` | после срабатывания концентрация заклинателя заканчивается |

Пример (Направляющий снаряд): `УСЛЭФ: ПРЕМ АТАКАМ ПО ЦЕЛИ` + `РАСХ: АТАКА ПО ЦЕЛИ 1` + `ДО: КОНЕЦ СЛЕДУЮЩЕГО ХОДА ИСТОЧНИКА`.

#### 6.12. Фильтры существ

| Запись | Смысл |
|---|---|
| `ТОЛЬКО ЕСЛИ: ТИП зверь, ИНТ не больше 3` | на неподходящую цель заклинание не действует |
| `ТОЛЬКО ЕСЛИ: НЕ ТИП нежить` / `ТОЛЬКО ЕСЛИ: НЕ ТИП конструкт/нежить` | действует на всех, кроме этих типов (отрицание — `НЕ` **перед** `ТИП`) |
| `ЕСЛИ ТИП нежить: макс урон, пом спас` | добавка для подходящих целей |
| `ЕСЛИ НЕ ИММ яд: отравлен 1` | только для целей без иммунитета |
| `ЕСЛИ ТИП нежить: вр хп половина урона вместо урона` | нежить получает временные хиты вместо урона |
| `ЕСЛИ ТИП конструкт: без спас` | цель этого типа проваливает спасбросок автоматически |
| `ЕСЛИ ТИП нежить: прем спас` / `пом спас` | преимущество/помеха на спасбросок для этого типа |
| `ЕСЛИ ТИП конструкт: вр хп вместо урона` | урон превращается во временные хиты |
| `СЛУЧАЙНО d8: 1 = тип огонь; 2 = тип кислота; …; 8 = повтор 2` | случайный эффект на каждую цель |
| `ПОЛИМОРФ` | превращение цели (ведётся скриптом Transform) |

Вместо `<`/`>` пиши `не больше` / `не меньше`.

#### 6.13. Вторичная область (`secondaryArea`)

Для заклинаний «атака по цели, затем взрыв вокруг неё» (Ледяной кинжал):

```json
"secondaryArea": {
  "trigger": "attack",
  "origin": "target",
  "area": "5 фт круг",
  "target": "каждое существо",
  "name": "Ледяной кинжал — взрыв",
  "hidden": true,
  "damage": "({ПОВ}+2)d6",
  "damageType": "холод",
  "save": "DEX",
  "saveSuccess": "Нет урона",
  "excludePrimary": false
}
```

`trigger`: `attack` (при попадании или промахе) · `hit` (только при попадании). `origin` — только `target`.

#### 6.14. Реакции

`castingTime: "1 реакция"`, `range: "Реакция"` или `"Реакция 60 фт"`, строки в `description`:

| Строка | Значения |
|---|---|
| `ТРИГ:` | `ПОПАДАНИЕ` · `ПОПАДАНИЕ БЛИЖНЕЕ` · `ПОПАДАНИЕ ДАЛЬНЕЕ` · `ПОЛУЧЕН УРОН` · `АТАКА` · `ЗАКЛИНАНИЕ` · `ВХОД` · `ВЫХОД` · `ПАДЕНИЕ` · `НАЛОЖЕНИЕ ЭФФЕКТА: очарован` |
| `УСЛ:` | `ВИДИТ ИСТОЧНИК` · `ВИДИТ ЦЕЛЬ` |
| `РЕЗ:` | `КД +5` · `ОТМЕНА ПОПАДАНИЯ` · `ПОМ АТАКЕ` · `ПРЕМ АТАКЕ` · `ПЕРЕБРОС АТАКИ` · `УРОН 0` · `УРОН -1d10+3` · `ОТМЕНИТЬ ЗАКЛИНАНИЕ` · `ОТРАЖЕНИЕ` · `ИСПОЛНИТЬ` · `СОПРОТИВЛЕНИЕ ТИПУ огонь/холод` · `СДВИГ ИСТОЧНИКА` |
| `Субъект:` | `себя` · `союзник` · `враг` · `любой` — чьё событие |
| `Цель реакции:` | `источник` · `цель события` · `себя` |

`РЕЗ: ИСПОЛНИТЬ` выполняет само заклинание (урон, спасбросок) по `Цель реакции`. Контрзаклинание и Рассеивание выбирают круг ячейки при срабатывании.

#### 6.15. Дарованные действия

Заклинание может положить в книгу заклинаний получателя служебное действие (без ячейки), которое исчезает с концом концентрации или зарядов:

```
ДАРУЕТ: xge-dragon-s-breath-fire, ЗАРЯДЫ 6, ХОДЫ 600
ДАРУЕТ СЕБЕ: xge-storm-sphere-bolt
```

- `ДАРУЕТ:` — цели заклинания; `ДАРУЕТ СЕБЕ:` — заклинателю. `ЗАРЯДЫ N` — число использований, `ХОДЫ N` — срок.
- Дарованное действие — **отдельная запись** в том же массиве: `id` = id заклинания + суффикс, `name` = «<Название заклинания>: <действие>», `level` = 0, `castingTime` — каким действием используется, `components` все `false`, в Примечании — «дарованное действие заклинания «…» — исчезает с концом заклинания». Ставь её в массиве перед основным заклинанием.
- С вариантами: под каждым `ВАРИАНТ:` своя строка `ДАРУЕТ:`.

#### 6.16. Спецэффекты `AD5ЭФФ`

Строка `AD5ЭФФ: {JSON}` — готовые обработчики. Используй только эти виды, ключи — как в примерах:

| kind | Пример | Для чего |
|---|---|---|
| `mark` | `{"kind":"mark","formula":"1d6","type":"некротическая энергия","checkAbility":"strength","duration":600}` | метка с доп. уроном по цели, переносится (Метка охотника, Сглаз) |
| `retaliation` | `{"kind":"retaliation","noTemp":true,"formula":"2d8","type":"огонь","duration":100}`; `{"kind":"retaliation","amountFromTemporary":true,"type":"холод","duration":600}`; добавки `"anyAttack":true,"range":10` | урон атакующему (Огненный щит, Доспех Агатиса, Покров тени) |
| `armor` | `{"kind":"armor","armorAttribute":"ad5_armor_worn","base":13,"duration":4800}` | КД без доспеха (Доспехи мага) |
| `protection` | `{"kind":"protection","duration":100}` | Защита от добра и зла |
| `heroism` | `{"kind":"heroism","amountFromSpellAbility":true,"duration":10}` | временные хиты каждый ход |
| `duel` | `{"kind":"duel","dcAttribute":"spell_save_dc","range":30,"duration":10}` | Вызов на дуэль |
| `periodic` | `{"kind":"periodic","order":"save-damage-end","formula":"4d10","type":"психический","dcAttribute":"spell_save_dc","ability":"wisdom","timing":"end","condition":"испуган","duration":10}` | урон с повторным спасброском (Смертельный ужас) |
| `link` | `{"kind":"link","duration":10,"range":30,"formula":"1d12","type":"электричество"}` | связь с повторным уроном (Ведьмин снаряд) |

Если ни один вид не подходит — опиши в `Примечание:` и ставь `automation: "partial"`.

### 7. Что скрипты НЕ делают — только `Примечание:`

- Призыв существ, фамильяров, скакунов (токен ведётся вручную).
- Видимость, освещение, иллюзии, маскировку, обнаружение и прорицание.
- Создание и изменение предметов, еды, укрытий, строений.
- Перемещение по плану, телепортацию на расстояние больше `телепорт N фт`, принудительное перемещение сложнее `ТОЛЧ`/`ТЯГ`.
- Социальные и сюжетные эффекты (общение, внушение, память, сны).
- Изменение строк атаки в листе (Дубинка, Магическое оружие частично) — пиши, что поправить.

Такие заклинания — обычная карточка: все обязательные поля, `description` из `ЗАКЛ` и `Примечание:` с кратким пересказом, `automation: "partial"`. Если у заклинания есть боевая часть (урон, состояние) — механизируй её, остальное в Примечание.

### 8. Как переводить текст заклинания в механику

1. **Есть бросок атаки** → `attack`. Урон → `damage`/`damageType`. Доп. эффект при попадании → прямая строка эффекта (`реакции 0 1`, `Замедление 10 1`).
2. **Есть спасбросок** → `save`, `saveSuccess` и строка `ПРВ: …; УСП: …`.
3. **Область мгновенная** → геометрия в `target`; **длится** → `, обл` + фазы (`ВХОД`, `ОБЛН`, `ПАСС`).
4. **Вокруг себя, без точки** → `range: "На себя"`, `ВКР круг N фт`.
5. **Бафф** → `range` по книге, `target` — кого, строка модификатора с длительностью в раундах. На себя — `range: "На себя"`.
6. **Повторяющийся спасбросок** → `состояние ХАР{DC} N`.
7. **Повышение круга** → `higherDieCount`/`higherDieType`/`higherText`; цели — `ЦЕЛЕЙ: N+{ПОВ}`; длительность — `ДЛИТЯЧ`. Если рост нельзя выразить — в Примечание: «на каждый круг выше N-го … (поправьте)».
8. **Действие каждый ход без ячейки** → `ПОВТОР: действие` или дарованное действие.
9. **Реакция** → §6.14.
10. **Остальное** → `Примечание:`.

Длительность в раундах: 1 раунд = 1, 1 минута = 10, 10 минут = 100, 1 час = 600, 8 часов и дольше = 999 (или 4800 в `AD5ЭФФ`).

### 9. Баланс авторских заклинаний

Ориентир — урон официальных заклинаний того же круга (DMG, гл. 9):

| Круг | Одна цель | Несколько целей |
|---|---|---|
| Заговор | 1d10 | 1d6 |
| 1 | 2d10 | 2d6 |
| 2 | 3d10 | 4d6 |
| 3 | 5d10 | 6d6 |
| 4 | 6d10 | 7d6 |
| 5 | 8d10 | 8d6 |
| 6 | 10d10 | 11d6 |
| 7 | 11d10 | 12d6 |
| 8 | 12d10 | 13d6 |
| 9 | 15d10 | 14d6 |

- Концентрация, длительный контроль или зона — урон на 25–50% ниже.
- Состояние «выводит из боя» (паралич, ошеломление, изгнание) — спасбросок снятия каждый ход.
- Сильный эффект без спасброска — только на себя или с ограничением целей.
- Помни правила кампании: крит-спасброски (натуральные 1 и 20), автокрит по парализованному.

### 10. `automation`

- `"full"` — всё, что влияет на бой, ведут скрипты; Примечание не обязательно или подсказывает порядок нажатий.
- `"partial"` — часть эффекта вручную (§7) или рост по кругу не выражен директивами. Примечание обязательно: что именно делается руками.

### 11. Чек-лист перед выводом

1. Ответ — один блок ```json с массивом; JSON валиден.
2. Название — официальное по dnd.su; английское — первым в `aliases`.
3. Учтены правила Арвенора (§2); удалённые заклинания не созданы.
4. Есть все обязательные поля; `id` — латиница, с префиксом источника.
5. `description` начинается с `ЗАКЛ`; механика — по строке на директиву, через `\n`.
6. Типы урона — только из §5.2; формулы — только `0-9 d + - * / ( )`; кириллическая «д» допустима только внутри строк эффектов (`1д4`).
7. При `save` есть строка `ПРВ: …; УСП: …`; при спасброске снятия — `ХАР{DC}` слитно.
8. У каждого модификатора и состояния — длительность в раундах.
9. `range: "На себя"` — только если цель сам заклинатель, область от себя или `ВКР`.
10. Концентрация — и в `duration`, и `"concentration": true`.
11. Повышение круга описано полями `higher*`, `ЦЕЛЕЙ`, `ДЛИТЯЧ` или в Примечании.
12. Дарованные действия — отдельными записями перед основным заклинанием.
13. Нет HTML, Markdown и таблиц внутри строк.

# Заклинания PHB (2014): что покрывает автоматизация AD5

Состояние сборки на ветке `claude/confident-bell-k7s63s`: AutoDamage 4.3.153, Effect Turns 1.6.12, Areas 2.25.1, Phases 1.1.5, Condition Engine 1.2.16, Movement 2.3.8, Reactions 1.6.11, Concentration 1.2.10, Spell Library 2.3.19.

## Как считалось

- Учитывалась только **боевая механика**. Нарративные части заклинаний, разведка и бытовая магия не рассматривались.
- **Призывы** (Find Familiar, Conjure …, Animate Dead, Spiritual Weapon и т. п.), **видимость** и **создание предметов** по решению кампании ведутся штатными средствами Roll20 и в таблицу не входят.
- Оценка по возможностям синтаксиса; новые механики проверены в эмуляторе Roll20 с настоящими скриптами и листом.

## Новые механики и синтаксис

| Механика | Синтаксис (строка описания) | Заклинания |
|---|---|---|
| Сопротивление/иммунитет баффом | `сопр огонь 10`, `сопр огонь/холод 10`, `сопр огонь 25% 10`, `сопр все 10`, `имм яд 10` | Blade Ward, Stoneskin, Protection from Energy, Protection from Poison, Mind Blank (часть) |
| Охранная связь | `охранная связь 600` + `сопр все 600` + `кд 1 600` + `спас ВСЕ +1 600` | Warding Bond |
| Снятие состояний и эффектов | `снимает ослеплён/оглохший/отравлен/парализован`, `снимает проклятие`, `снимает истощение 1`, `снимает снижение максимума`, `рассеивает 3` | Lesser/Greater Restoration, Remove Curse, Dispel Magic, Calm Emotions, Heal (лечение + снятие) |
| Умирание (только персонажи) | автоматически; `стабилизирует`, `возвращает к жизни 1`, `защита от смерти 480` | Spare the Dying, Healing Word (правило Арвенора), Revivify, Death Ward |
| Максимум хитов | `макс хиты +5 999` | Aid |
| Запрет лечения | `без лечения` + `ДО: НАЧАЛО СЛЕДУЮЩЕГО ХОДА ИСТОЧНИКА` | Chill Touch |
| «Не ниже 1 хита», снижение максимума | `НЕ НИЖЕ 1`, `СНИЖ МАКС` | Harm |
| Лечение от урона | `ВАМП` / `ВАМП 25%` | Vampiric Touch |
| Порог хитов | `ХИТЫ<=100: смерть`, `ХИТЫ<=150: ошеломлён ТЕЛ{DC}`, ярусы строками | Power Word Kill, Power Word Stun, Divine Word |
| Помеха атакам по цели | `УСЛЭФ: ПОМ АТАКАМ ПО ЦЕЛИ` | Blur, Holy Aura, Foresight |
| Преимущество только заклинателю | `УСЛЭФ: ПРЕМ АТАКАМ ИСТОЧНИКА ПО ЦЕЛИ` + `РАСХ: АТАКА ИСТОЧНИКА ПО ЦЕЛИ 1` | True Strike |
| Помеха следующей атаке цели | `УСЛЭФ: ПОМ АТАКАМ ЦЕЛИ` + `РАСХ: ЦЕЛЬ АТАКОВАЛА 1` + `ДО: КОНЕЦ СЛЕДУЮЩЕГО ХОДА ЦЕЛИ` | Vicious Mockery |
| Разовый куб к проверке/спасброску | `проверка ВСЕ +1д4 10` + `РАСХ: ПРОВЕРКА 1`; `спас ВСЕ +1д4 10` + `РАСХ: СПАСБРОСОК 1` | Guidance, Resistance |
| Преимущество на все спасброски | `прем все 10` | Holy Aura, Foresight |
| Счёт успехов/провалов | `опутан ТЕЛ{DC} СЧЁТ 3 → окаменел` | Flesh to Stone, Contagion, Prismatic Spray (индиго) |
| Нарастающий урон | в фазе `РОСТ 1д6` (`ОКОН: ПРВ: Урон1, РОСТ 1д6; …`) | Delayed Blast Fireball |
| Случайный эффект | `СЛУЧАЙНО d8: 1 = тип огонь; …; 6 = нет урона, опутан ТЕЛ{DC} СЧЁТ 3 → окаменел; 8 = повтор 2` | Prismatic Spray |
| Замешательство | `замешательство МДР{DC}` — d10 поведения в начале хода | Confusion |
| Перехват атак | `зеркальные образы 10` | Mirror Image |
| Исчезновение с поля | `изгнан`, `в лабиринте ПРОВЕРКА ИНТ20`, `мерцание 10`, `эфирный план` | Banishment, Maze, Blink, Etherealness, Plane Shift (боевое изгнание) |
| Остановка времени | `остановка времени` — 1d4+1 ходов, кнопка ГМ | Time Stop |
| Приказ | `приказ: ниц` / `стой` / `беги` / `брось` / `ко мне` | Command |
| Подчинение | `подчинён МДР{DC}` (+ `очарован`) — токен у игроков заклинателя, спасбросок при уроне | Dominate Beast/Person/Monster |
| Ускорение / Замедление | `ускорен 10` (скорость ×2, доп. действие, после — вялость); `замедлен МДР{DC}, КД -2, спас ЛОВ -2, нет реакций` (ограничения объявляются) | Haste, Slow |
| Скорость, телепорт | `скорость +10 600`; `телепорт 30 фт` — следующее перемещение токена без затрат скорости и провоцирования | Longstrider, Misty Step, Dimension Door |
| Дрейф зоны | `ДРЕЙФ: 10` | Cloudkill, Incendiary Cloud |
| Кольцо | `КОЛЬЦО: 5` у круга | Blade Barrier (кольцо) |
| Опасная сторона стены | `СТОРОНА: 10` у линии | Wall of Fire |
| Несколько областей | `"10 фт куб 10×"` / `"40 фт круг 4×"` + `ОДИН РАЗ` | Fire Storm, Meteor Swarm (только мгновенные области; несколько постоянных панелей — Wall of Force — пока вручную) |
| Антимагия | `АНТИМАГИЯ: 5` / `АНТИМАГИЯ: КРУГ-1` у области; `АНТИМАГИЯ: ВСЕ` у ауры | Globe of Invulnerability, Antimagic Field |

Попутно исправлено: урон фаз со спасброском (`ВХОД`, `ОБЛН`, `ОКОН` и др.) раньше считался по служебным кубам и давал 1 урон на компонент.

## Что осталось частично или вручную

| Чего нет | Заклинания |
|---|---|
| Подавление уже действующих эффектов внутри Антимагического поля (новые заклинания блокируются) | Antimagic Field |
| Многослойные стены и ловушки-триггеры | Prismatic Wall, Symbol, Glyph of Warding, Contingency |
| Изменение размера и характеристик листа | Enlarge/Reduce (размер токена), Feeblemind, Shillelagh, Magic Weapon (бонус токену, не оружию) |
| Сложные сценарии площадей | Storm of Vengeance, Earthquake, Tsunami, Reverse Gravity, Wind Wall (отражение снарядов), Forcecage |
| Ответный урон и особые сопротивления | Fire Shield (сопротивление есть, ответный урон вручную), Freedom of Movement, Aura of Purity |
| Регенерация каждый ход, несколько лучей одной атакой | Regenerate, Eldritch Blast (рост лучей), Scorching Ray |
| Ограничения по предмету/оружию | Heat Metal, Ray of Enfeeblement (половина урона Силой) |
| Скорость полёта, прыжок, рывок бонусным действием | Fly, Jump, Levitate, Expeditious Retreat |
| Запрет вербальных заклинаний в зоне | Silence |
| Bestow Curse (вариант «теряет действие»), Crown of Madness, Compulsion | приказ/подчинение покрывают часть, остальное — ГМ |

Повторное нажатие способности остаётся рабочим путём для заклинаний «повторите действие в следующий ход» (Call Lightning, Sunbeam, Witch Bolt и т. п.).

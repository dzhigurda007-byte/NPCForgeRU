# Заклинания дополнений: что нужно для автоматизации боевых

Разбор заклинаний из дополнений кампании относительно сборки AutoDamage 4.3.158 / Effect Turns 1.6.15 / Areas 2.28.0 / Spell Library 2.3.23.

**Не автоматизируются** (по решению кампании): призыв, видимость и иллюзии, взаимодействие с окружением, создание предметов для дальнейшего использования, чисто нарративные и визуальные эффекты, принудительное перемещение и повышение скорости. Если у заклинания такая часть только одна, автоматизируется остальное (урон, спасбросок, состояние), а она остаётся примечанием.

## Рекомендуемый порядок

1. **Группа A** — один проход данных и импорт отдельным файлом `imports/expansion-spells.json` (как PHB): 52 заклинания.
2. Малые механики **4, 5, 7, 9–19** — 18 заклинаний.
3. Механики **3, 6, 8** — средние, 6 заклинаний.
4. Механики **1 и 2** — самые объёмные (дарованные действия с зарядами, новые окна реакций), но закрывают 15 частых боевых заклинаний.

Названия на русском даны по распространённым переводам; при импорте в `aliases` добавляются английские, поиск работает по обоим.

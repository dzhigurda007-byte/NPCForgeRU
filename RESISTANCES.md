# AD5 4.2: процентные сопротивления и уязвимости

Замените установленный AutoDamage файлом из этой ветки, перезапустите API. Вторую копию AD5 не устанавливайте.
NPC Forge 2.5.1, Areas 1.3, окно JSON и накопительные раны сохранены.

## Где хранить
- Персонаж игрока: поле «Слабости» листа D&D 5e 2014 (атрибут flaws).
- NPC: «Заметки мастера» самого персонажа (character.gmnotes), не заметки токена.
Для NPC под управлением игрока также используются заметки мастера.

Пишите отдельной строкой, без кавычек и заголовка перед первым типом:
```
огонь: 25, звук: 50, кислота: -50
```
Можно разделять записи запятыми, точками с запятой или переносами строк. HTML абзацы редактора заметок поддерживаются.
Положительное число уменьшает урон на указанный процент; отрицательное увеличивает.
100 означает иммунитет к этому типу; -100 — двойной урон; 0 или отсутствие типа — без изменения.
Проценты больше 100 и противоречивые повторения одного типа вызывают ошибку, HP не списываются.
Нераспознанные типы и обычный текст заметок не применяются. Используйте точные имена ниже.

Типы: кислота, дробящий, холод, огонь, силовое поле, электричество, некротическая энергия, колющий, яд, психический, излучение, рубящий, звук. Поддерживаются английские эквиваленты AD5.
Лечение не изменяется этими записями.
Это пользовательская процентная механика с типами D&D, а не автоматическое чтение текстовых условных сопротивлений из всех официальных статблоков.
Условия вроде «от немагического оружия» автоматически не определяются.

## Порядок
Атака: попадание → урон по типам → сопротивления/уязвимости → временные HP → HP → раны.
Спасбросок: результат → полный/половина/нет урона → сопротивления/уязвимости → временные HP → HP → раны.
При промахе сопротивления не читаются. При ожидании спасброска HP не меняются.
Компоненты одинакового типа объединяются. По каждому типу: множитель AD5 округляется вниз; половина при успешном спасброске — вверх (прежнее правило кампании); итог процентного модификатора — вниз. Затем суммы типов складываются.
Пример: 20 огня, успешный спасбросок с половиной, огонь: 25 → 10 → 7.5 → 7 урона.

## Нанести полный урон
В отчёте мастеру есть кнопка «Нанести полный урон».
Она ЗАМЕНЯЕТ результат того же применения на урон без сопротивлений и уязвимостей:
- не делает повторного броска;
- сохраняет результат спасброска, состояния и множитель AD5;
- не наносит повторно уже списанный урон;
- при уязвимости может вернуть избыточно списанные HP;
- пересчитывает рану и временные HP от исходного состояния;
- повторное нажатие блокируется.
При успехе «нет урона» кнопка не позволяет обойти спасбросок и не отображается для нулевого результата.
Если после эффекта HP, состояния или раны изменились, замена останавливается как обычная безопасная отмена.
Undo/redo после замены относится к новому результату.
Кнопка доступна только GM, в том числе в отчётах нескольких целей.

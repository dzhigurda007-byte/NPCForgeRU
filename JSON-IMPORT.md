# Импорт NPC без заметок — NPC Forge 2.5.1

## Многострочное окно «Создать»
1. В Roll20 Mod Scripts замените старый NPCForge содержимым файла NPCForge из этой ветки. AD5/Areas менять не нужно.
2. Установите браузерный менеджер пользовательских скриптов, например Tampermonkey.
3. Создайте в нём новый скрипт и вставьте содержимое NPCForge-JSON-Window.user.js, сохраните.
4. Перезагрузите игровое поле Roll20. Внизу слева появится кнопка NPC JSON.
5. Нажмите её, вставьте JSON и нажмите «Создать». Есть флажок создания токена.
6. Результат покажет NPC Forge в личном сообщении мастеру. Надпись окна «команда передана» не является подтверждением успешного импорта.

Это браузерный скрипт: не вставляйте файл .user.js в Roll20 Mod Scripts.
NPC JSON открывает настоящее многострочное окно. Создание на стороне NPC Forge разрешено только GM.
Если поле чата содержит черновик, окно не затирает его и просит освободить поле.
Повторная отправка после закрытия и открытия окна создаёт новый NPC; автоматического объединения по имени нет.
Ауры, действия, состояния и другие поля используют прежний формат JSON.

## Только макрос, без браузерного скрипта
Создайте макрос NPC-JSON, включите In Bar:
```
!npc-json --token --json|?{Вставьте JSON NPC одной строкой}
```
Откроется стандартный запрос Roll20. Это короткое однострочное поле со стандартной кнопкой подтверждения, а не многострочное окно.
Для длинного JSON и строк с макросами Roll20 используйте браузерное окно: оно кодирует содержимое до передачи в чат.
Пример для стандартного запроса:
```json
{"name":"Тестовый страж","cr":"1","role":"soldier"}
```

## Прямая команда
```
!npc-json --token --json|{"name":"Тестовый страж","cr":"1","role":"soldier"}
```
Без --token создаётся только лист. При массиве создаются все листы и токен только первого NPC.
Максимум 50 NPC за импорт, длина передаваемых данных максимум 250000 символов; Roll20 может иметь собственные ограничения размера сообщения.

## Проверка
Пройдены тесты с имитацией Roll20: прямой/кодированный JSON, неправильный JSON, пустой массив, проверка GM, создание токена, а также регрессии AD5 4.0.
Запуск из корня репозитория: node tests/direct-json.cjs
Браузерное окно использует элементы #textchat-input textarea и #textchat-input button. В живом Roll20 интерфейс не проверялся; при изменении интерфейса окно покажет ошибку поиска поля чата.

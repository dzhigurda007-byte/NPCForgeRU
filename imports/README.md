# Импорт заклинаний PHB в AD5 Spell Library

Два файла дополняют встроенную библиотеку (47 записей; раньше было 54 — раздельные варианты Цветного шарика, Слепоты/глухоты и Духовных стражей объединены в записи с меню) до полного списка заклинаний «Книги игрока» (2014):

| Файл | Круги | Записей |
|---|---|---|
| `phb-spells-1-krug-0-2.json` | заговоры, 1, 2 | 121 |
| `phb-spells-2-krug-3-9.json` | 3–9 | 193 |

Заклинания, которые уже есть во встроенной библиотеке (Огненный снаряд, Огненный шар, Лечащее слово по правилу Арвенора и др.), в файлы не входят — встроенные версии настроены под кампанию.

## Как импортировать

1. В чате Roll20 (как ГМ): `!ad5spell-json` — откроется раздатка **«AD5 Spell Library — JSON Import»**.
2. Вставьте в её **GM Notes** содержимое первого файла целиком и сохраните.
3. Нажмите «Добавить / обновить» в окне JSON Manager (или `!ad5spell-json-import`).
4. Повторите шаги 2–3 со вторым файлом (импорт за раз — не более 200 записей).

Повторный импорт безопасен: записи с теми же `id` (`phb-…`) обновляются.

## Что внутри

- `id` — `phb-<английское название>`, `aliases` — английское и русское название (поиск работает по обоим).
- Механика записана синтаксисом AD5 (урон, спасброски, состояния, баффы, зоны, кары, реакции и новые директивы: `сопр`, `стабилизирует`, `ХИТЫ<=`, `СЛУЧАЙНО`, `телепорт`, `ДРЕЙФ`, `АНТИМАГИЯ` и т. д.).
- `automation: "full"` — скрипты ведут заклинание сами; `"partial"` — часть делается вручную, что именно — в строке «Примечание» описания.
- Призывы, видимость, создание предметов и прочие нарративные заклинания добавлены как обычные карточки с кратким описанием.
- Описания — краткие пересказы механики, а не текст книги; полные формулировки смотрите в PHB.

## Проверено

Все 166 механических заклинаний импортированы и сотворены в эмуляторе Roll20 с настоящими скриптами и листом персонажа; ошибок разбора нет. Заклинания на несколько целей (Благословение, Волшебная стрела и т. п.) запрашивают выбор целей — это штатный режим.

## Обновление встроенных заклинаний

`builtin-updates-2026-10.json` — новые версии 9 встроенных заклинаний (`mode: replace`, те же `id`): Огненная буря и Метеоритный дождь (`ОБЛАСТИ: N` — несколько областей одним «Применить»), Смертельное облако (`ДРЕЙФ`), Стена огня (`СТОРОНА`), Направляющий снаряд, Злая насмешка, Леденящее прикосновение, Касание вампира, Лечащее слово (Арвенор). Импортируйте так же, как файлы выше. Если у вас уже стоит Spell Library 2.3.20, эти версии в ней есть — импорт ничего не испортит. Уже добавленные в лист заклинания удалите из листа и добавьте заново.

## Стены (октябрь 2026, Areas 2.26.0)

В файлах обновлены Каменная, Ледяная, Силовая и Радужная стены, Стена ветра, Стена шипов, Шипы и Клинковый барьер — теперь они ведутся автоматически: панели («Новая панель k/10»), вытеснение существ, токены прочности, пролом Ледяной стены, промах снарядов сквозь Стену ветра, цена движения в шипах. Импортируйте оба файла повторно (записи обновятся по `id`), затем удалите эти заклинания из листа и добавьте заново.

Токены прочности создаются без картинки. Чтобы у них была своя картинка, ГМ выделяет любой токен с нужной картинкой из своей библиотеки и пишет `!ad5-area brick-image`.

## Все встроенные заклинания

`builtin-spells-all.json` — все 47 встроенных заклинаний Spell Library 2.3.21 (`mode: replace`, те же `id`). Импорт возвращает встроенные записи к версии скрипта, например после ручных правок или чтобы перенести их в другую игру. Импортируется так же, как файлы выше, за один раз.

## Каталог в игре

`!ad5spell-list` (или кнопка «Каталог» в меню библиотеки) показывает все загруженные заклинания со степенью автоматизации: ● AD5 готово, ◐ частично (с тем, что ведётся вручную), ○ вручную (карточка без автоматики). Фильтры по степени, кругу и источнику (встроенные / импорт), страницы по 25. Полный список — в раздатке «AD5 Spell Library — Каталог», она обновляется при каждом открытии каталога.
